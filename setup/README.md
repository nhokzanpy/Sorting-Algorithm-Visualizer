\# Setup - Sorting Algorithm Visualizer



\## Requirements



\- Windows 10/11

\- Qt 6.5 or later

\- CMake 3.19 or later

\- C++ compiler compatible with Qt 6

\- Qt components:

&#x20; - Core

&#x20; - Widgets



\## Build



Open the project using Qt Creator or configure it with CMake.



The project uses CMake and requires Qt 6.



\## Run



Build the `SortingVisualizer` target and run the generated executable.



\## Project



Sorting Algorithm Visualizer is a C++/Qt application for visualizing and comparing sorting algorithms.
