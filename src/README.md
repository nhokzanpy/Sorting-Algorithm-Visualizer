\# Source Code



The source code of Sorting Algorithm Visualizer is organized in the

project root according to the current CMake configuration.



Main source directories:



\- `algorithms/` - Sorting algorithm implementations

\- `benchmark/` - Benchmark functionality

\- `models/` - Data models and sorting results

\- `pages/` - Application pages

\- `student/` - Student Lab functionality

\- `widgets/` - UI widgets

\- `resources/` - Application resources



Main source files:



\- `main.cpp`

\- `mainwindow.cpp`

\- `mainwindow.h`

\- `mainwindow.ui`



The project is built using `CMakeLists.txt`.
